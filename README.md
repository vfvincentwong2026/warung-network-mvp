## 📖 项目简介

**Warung Network** 是一个以**雅加达大学城 Warung（印尼传统小卖部）终端网络**为基础的「新品发射台」，帮助中国消费品牌低成本验证并进入印尼市场。

蜜雪冰城们在印尼开了 2,600 家店——但只有巨头烧得起自建渠道。腰部品牌（年营收 5,000 万-5 亿）想进印尼，缺的不是野心，是**一手市场数据和真实终端**。

我们的答案：

- 🗺️ **雅加达大学城 Warung 终端网络**：覆盖 UI、UNJ、BINUS 等 9 所高校周边 1 公里高密度零售终端
- ⚡ **48 小时闪电测**：新品样品进入 10 家校园 Warung 封闭式盲测，3 天出真实市场反馈
- 📊 **消费快报**：雅加达大学生消费洞察，公开数据 + 一手问卷 + 终端实测
- 🤝 **市场进入服务**：铺货代理、BPOM/清真合规咨询、渠道共建

### 为什么是印尼校园

- 印尼 **2.85 亿人口**，年龄中位数约 **30 岁**，Z 世代约 **7,500 万**
- QRIS 扫码支付 2024 年交易量增长 **175%**，超 3,000 万中小微商户接入
- 约 **300 万家 Warung** 贡献印尼零售约 **68%** 份额——其中校园段从未被系统组织过

## 🚀 当前阶段：需求验证（W1-W4）

按方案 v2.0，项目处于**双轨验证期**：

- **轨道 A（国内）**：拿快报样板与招商单页，在出海社群完成 20 个品牌 1v1 需求验证
- **轨道 B（雅加达）**：UI Depok 踩点 100 家目标 Warung + 30 位店主建联 + 店主群运营

**Go/No-Go**：≥3 份报告付费 或 ≥1 个档期预付 → 启动网站建设与渠道激活。

详见 [docs/方案-v2-品牌出海发射台.md](docs/方案-v2-品牌出海发射台.md)。

## 🗺️ 路线图

```

```
