# Google Sheets 建表 SOP（手工 5 分钟版）

> 背景：自动化通道不可用（gcloud CLI 未安装；浏览器桥接端口被 VPN 占用），
> 所以用「导入 CSV + 粘贴一条公式 + 点 8 下鼠标」的方式完成，效果完全一样。
> 所需文件：`deliverables/内部总表-导入模板.csv`（已生成，含 38 家现有点位）

你已打开的表格：https://docs.google.com/spreadsheets/d/1971OoJ2G9gJz8c61XeM9xxjxYqIu5jKxat2i44il25E/edit

---

## 第 1 步：改表格标题（10 秒）

点左上角「未命名电子表格」→ 输入 `Warung Network 数据库` → 回车。

## 第 2 步：把「工作表1」改名为「内部总表」（10 秒）

底部 tab「工作表1」上**双击** → 输入 `内部总表` → 回车。

## 第 3 步：导入点位数据（1 分钟）

1. 菜单「文件」→「导入」→「上传」→ 选择 `deliverables\内部总表-导入模板.csv`
2. 导入设置：**导入位置选「替换当前工作表」**，分隔符选「逗号」，点「导入数据」
3. 检查：A1 应为 `id`，共 39 行（1 表头 + 38 点位）

## 第 4 步：建「公开数据」tab + 粘贴公式（1 分钟）

1. 点左下角 **「+」** 新建工作表 → 双击改名为 `公开数据`
2. 点 A1 单元格，粘贴下面这条公式，回车：

```
=QUERY('内部总表'!A:M, "select A, B, C, D, E, F, G, K where A is not null", 1)
```

3. 检查：A1 应显示 `id`，A 到 H 列共 39 行数据自动镜像过来

> 这条公式的含义：从内部总表只取 8 个非敏感列（id/店名/大学/经纬度/品类/状态/周订单），
> 店主姓名、WhatsApp、备注**永远不会**进入这个 tab。

## 第 5 步：发布为 CSV（2 分钟，最关键）

1. 菜单「文件」→「共享」→「发布到网络」
2. 弹窗中第一个下拉框：**选择「公开数据」**（⚠️ 不是「整个文档」！）
3. 第二个下拉框：选择 **「逗号分隔值 (.csv)」**
4. 点「发布」→ 确认弹窗点「确定」
5. **复制生成的链接**（形如 `https://docs.google.com/spreadsheets/d/.../pub?gid=xxxxx&single=true&output=csv`）

## 第 6 步：把链接发给我

把链接粘到对话里发给我，我写入网站配置并联调推送。
（或自己动手：编辑 `assets/js/data.js` 第 38-39 行，URL 填入 `SHEET_CSV_URL`，`SHEET_ENABLED` 改为 `true`，提交推送即可）

## 日常录入（地推手机端）

- 手机装 Google Sheets App → 打开「Warung Network 数据库」→ 只在「内部总表」tab 末尾加行
- 必填 7 列：id / name / university_id / lat / lng / categories / status
- 状态只能填这五个英文词之一：`target` `contacted` `negotiating` `signed` `active`
- 坐标站在店门口用手机地图读数；公开 tab 和网站会**自动同步**（约 5 分钟缓存延迟）

## 常见坑

| 现象 | 原因与解法 |
|---|---|
| 公式显示 #REF! 或红色 | 第 2 步改名没改成「内部总表」，或第 4 步 tab 名不是「公开数据」，名字必须一字不差 |
| 网站地图没变 | 发布后 Google 有约 5 分钟缓存；强刷页面（Ctrl+F5） |
| 发布弹窗里找不到「公开数据」 | 第 4 步没建 tab，回到第 4 步 |
